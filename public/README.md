# Static Assets Directory (public/)

Place your brand images, icons, and logos here. In Next.js, files in this directory are served from the root path:

- `public/logo.svg` or `public/logo.png` -> accessible via `/logo.svg` or `/logo.png`
- `public/icon.svg` or `public/icon.png` -> accessible via `/icon.svg` or `/icon.png`
- `public/favicon.ico` -> accessible via `/favicon.ico`
